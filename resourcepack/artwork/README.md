# Original skin artwork

`original-skins.zip` stores the 815 inventory sprites and 1,377 inspect layers supplied in the original Fusion HD 1.2.0 pack, without modifying their bytes. `SOURCE.json` records every source hash. Builds and runtime exports derive opaque meshes from these images; new catalog entries use the configured renderer. The project keeps model definitions and animation profiles current rather than importing old JSON.

The custom server font images live separately in `resourcepack/fusion` and remain unchanged. Asset provenance does not establish third-party redistribution rights.
